# Toast

`@ilokesto/toast`는 React를 위한 완성형 알림 시스템입니다. 익숙한 `toast.*` 퍼사드, 자동 닫기와 마우스 오버 시 일시 정지, Promise 상태 전환, 접근성 기본값, 위치 설정, 사용자 지정 렌더링, 선택적 최상위 레이어 표시를 제공합니다.

## 설치

```package-install
@ilokesto/toast react react-dom
```

## 가장 짧은 실용 예제

```tsx lineNumbers
import { Toaster, toast } from '@ilokesto/toast';

export function App() {
  return (
    <>
      <button onClick={() => toast.success('저장했습니다')}>저장</button>
      <Toaster position="top-right" />
    </>
  );
}
```

`toast.*`를 호출하기 전에 대응하는 `Toaster`가 마운트되어 있어야 합니다. 기본 런타임은 `<Toaster />`가 마운트된 뒤 등록됩니다.

## Toast와 Overlay 중 무엇을 선택할까요?

일시적인 알림에는 `@ilokesto/toast`를 선택하세요. 표시 시간 타이머, 마우스 오버 시 일시 정지, 상태 아이콘, 라이브 리전 속성, 위치, 표시 개수 제한, Promise 갱신, 종료 지연을 이미 처리합니다. 다른 오버레이 계열이나 완전히 사용자 지정된 라이프사이클을 만들 때만 [`@ilokesto/overlay`](/ko/overlay)를 선택하세요. 사용자의 작업을 막고 결정을 기다려야 한다면 [`@ilokesto/modal`](/ko/modal)이 알맞습니다.
